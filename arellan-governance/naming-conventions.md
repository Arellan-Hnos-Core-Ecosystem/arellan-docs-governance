# Universal System Naming Conventions

## 1. Code-Level Naming
- **Variables & Functions:** camelCase (e.g., `calculateDynamicInvoiceQR`).
- **Classes & Interfaces:** PascalCase (e.g., `AuditTrailInterceptor`).
- **Database Tables:** snake_case, pluralized (e.g., `cashbox_ledger_entries`).

## 2. Folder Formats
Use kebab-case for all microservice folder arrays and physical asset paths.
