# Database Schema Overview & Referential Constraint Rules

## 1. Physical Layer Mandates
The central database runs on PostgreSQL 16+. All tables must utilize autogenerated UUIDs (v4) instead of serial integers as Primary Keys to facilitate zero-collision sharding during future SaaS tenant migrations. Every table row must contain `created_at`, `updated_at`, and `deleted_at` (for soft-delete patterns).

## 2. Core Operational Tables (DDL Structural Mappings)

### Identity & Security Modules
- `accounts`: Stores core credentials. `id (UUID)`, `email (VARCHAR)`, `password_hash (TEXT)`, `mfa_secret (VARCHAR)`, `status (ENUM: ACTIVE, INACTIVE, TERMINATED)`.
- `account_roles`: Strict mapping. `account_id (UUID)`, `role (ENUM: OWNER, FINANCE, MECHANIC, APPRENTICE, CLIENT)`.
- `biometric_templates`: Biometric hashes. `id (UUID)`, `account_id (UUID)`, `fingerprint_index (INT)`, `template_hash (TEXT)`, `updated_at (TIMESTAMPTZ)`.

### Financial Control Modules
- `cashbox_sessions`: Operational cash registers. `id (UUID)`, `opened_by (UUID)`, `closed_by (UUID)`, `opening_balance (NUMERIC(12,2))`, `closing_balance (NUMERIC(12,2))`, `status (ENUM: OPEN, CLOSED)`.
- `financial_transactions`: Inflow/Outflow tracking. `id (UUID)`, `session_id (UUID)`, `type (ENUM: INFLOW, OUTFLOW)`, `amount (NUMERIC(12,2))`, `payment_method (ENUM: DYNAMIC_QR, POS, CASH)`, `reference_token (VARCHAR)`, `is_audited (BOOLEAN)`.
- `expense_authorizations`: Multi-sig approvals. `id (UUID)`, `requester_id (UUID)`, `approver_id (UUID)`, `amount (NUMERIC(12,2))`, `justification (TEXT)`, `attachment_url (TEXT)`, `status (ENUM: PENDING, APPROVED, REJECTED, DISBURSED)`.

### Forensic Audit Module
- `forensic_audit_logs`: Inmutable database logs.
  ```sql
  CREATE TABLE forensic_audit_logs (
      id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
      account_id UUID REFERENCES accounts(id),
      action_type VARCHAR(100) NOT NULL, -- e.g., 'MANUAL_CASHBOX_OVERRIDE'
      ip_address INET NOT NULL,
      client_payload JSONB NOT NULL, -- Full delta snapshot before change
      server_payload JSONB NOT NULL, -- Full delta snapshot after change
      created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
  );
  CREATE INDEX idx_forensic_action ON forensic_audit_logs(action_type);
